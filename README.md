# ОПИСАНИЕ ПРОЕКТА
## Название 
Автогенератор набора тестовых заданий ЕГЭ
## Проблема
Необходимо создавать индивидуальные наборы заданий ЕГЭ для учеников - надо регулярно проверять степень усвоения материала.
## Пользователь
Проект создается для школьного учителя информатики 11 класса.
## Основная функция
1. На вход подается банк заданий ЕГЭ.
2. На выходе формируется HTML-страница с заданиями.
Функциональность реализуется запуском программы на языке Python. Задания-исходники хранятся в формате JSON.
## Формат результата
Результатом является заданное количество индивидуальных наборов заданий ЕГЭ.
## Минимальный функционал
Сформировать N наборов из M тестовых заданий.
## Технологии
Использованы:
- язык программирования Python
- библиотеки json, os, shutil, BeautifulSoup
Результат представлен в формате HTML.
# ИНСТРУКЦИЯ ПО ЗАПУСКУ
Находясь в папке проекта, запустить скрипт:

	python scrapers/generate_task_set.py

Скрипт создаст в папке проекта папку 

	preview_set 

в которой создаст папки с вариантами заданий, а также ZIP-архивы этих папок для передачи ученикам.
