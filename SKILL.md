# Скилл: Поиск аналогичных заданий

## Назначение

Скилл предназначен для подбора задач из общего массива данных (`tasks.json`), которые максимально похожи на заданную задачу по своим характеристикам.

## Критерии аналогичности

Задача считается аналогичной, если она одновременно удовлетворяет двум условиям:
1. **Одинаковый номер ЕГЭ**: `ege_number` должен совпадать с номером искомой задачи.
2. **Пересечение по КЭС**: Задача должна относиться хотя бы к одному и тому же разделу КЭС (`kes_uuids`), что и исходная задача.

## Процедура выполнения

1. **Поиск исходной задачи**: Найти в `data_json/raw/tasks.json` задачу по переданному `task_uuid`.
2. **Извлечение признаков**: Получить `ege_number` и список `kes_uuids` этой задачи.
3. **Фильтрация базы**: Просмотреть все остальные задачи в файле и отобрать те, где:
    - `task.ege_number == source_task.ege_number`
    - `set(task.kes_uuids) & set(source_task.kes_uuids)` не пусто.
4. **Результат**: Вернуть список найденных задач (UUID и `original_id`).

## Запуск скилла

Для запуска передачи скиллу:
- `task_uuid` задачи, для которой ищутся аналоги.

Скилл возвращает список подходящих задач из `tasks.json`.
